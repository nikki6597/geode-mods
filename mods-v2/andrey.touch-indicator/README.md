# Touch Indicator — Geode Android

Target: Geometry Dash 2.2081, Geode v5.10.1, Android ARM32.

The mod draws a small white circle where the player touches the screen. It does not intentionally swallow the touch, so the Geometry Dash input should continue working normally.

## Build

The included GitHub Actions workflow builds the Android Geode package in the cloud. It is intended to avoid requiring a local PC/NDK setup.
